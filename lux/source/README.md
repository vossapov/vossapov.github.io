# Люкс — вихідний код локального застосунку

[Спочатку подивіться мобільний відеоогляд](https://vossapov.github.io/lux/review/). [Спробуйте публічне демо](https://vossapov.github.io/lux/).

## Запуск спеціалістом

Python 3.12+, Node.js для JS-перевірок. Системні залежності: `espeak-ng` для озвучення; Poppler (`pdftotext`, `pdftoppm`) для PDF. Файли інтерфейсу та модель розміщено поряд, у `lux/` цього репозиторію, без дублювання великих бінарних файлів.

```bash
git clone https://github.com/vossapov/vossapov.github.io.git
cd vossapov.github.io/lux/source
python3 -m venv .venv
. .venv/bin/activate
pip install -r requirements.txt
python prepare.py
LUX_PYTHON="$PWD/.venv/bin/python" LUX_HOST=127.0.0.1 bash start.sh
```

Відкрити `http://localhost:8080`. `prepare.py` копіює тільки відомі публічні ресурси до `demo/dist`. Приватні кампанії, вкладення та журнали створюються в `demo/creative-data`, поза вебкаталогом; вони не включені в репозиторій. Демонстраційні матеріали каталогу не є реальним товарним обліком.

## Генерація

Встановити Codex CLI з офіційного джерела та виконати `codex login` через ChatGPT. Перевірити `codex login status`. За потреби передати шлях до виконуваного файлу через `LUX_CODEX_BIN`. Потрібен доступний вбудований генератор зображень та невичерпані ліміти облікового запису. API-ключі OpenAI не використовуються; токени desktop-застосунку не витягуються. Одного встановленого ChatGPT Desktop недостатньо.

Міст генерації приймає запити тільки з localhost. Для використання генерації з телефонів потрібен окремий захищений серверний доступ із авторизацією та ролями. Не відкривайте поточний демосервер в інтернет.

## Що потрібно для впровадження

| Частина | Що підключити / завершити |
| --- | --- |
| Каталог | Джерело товарів, стабільні артикули, актуальні ціни й залишки, фото; правила синхронізації та показ часу оновлення. |
| Пошук | Реальні приклади запитів і фото, перевірка схожих модифікацій, HTTPS і підтримуваний браузер для голосу. |
| Мапа | Узгоджений план залу та адреса кожного товару. Поточні полиці й GPS демонстраційні. Позицію телефона всередині будівлі перевіряти окремим пілотом. |
| Кампанії | Оригінал логотипа, затверджені правила бренду й фото, права працівників, погодження перед публікацією. |
| Генерація | Постійно доступний робочий ПК/сервіс, авторизований Codex, контроль лімітів, збереження файлів і резервні копії. |
| Соцмережі | Офіційна авторизація сторінок, дозволи на публікацію, точне зіставлення форматів і сторінок. |
| Розклад SMM | Спільна база замість localStorage, фоновий виконавець, часовий пояс, повтори, захист від дублювання, підтвердження від соцмереж. |
| Команда | Вхід, ролі, журнал дій, власник процесу й правила роботи з даними. |
| Друк | Вимоги друкарні: вильоти, профіль кольору, перевірка шрифтів і роздільності. Поточний PDF — RGB-макет для погодження. |

## Перевірки

Після `prepare.py`:

```bash
python scripts/check_creative.py
node scripts/check_campaign_wizard.js
node scripts/check_marketing.js
node scripts/check_store_map.js
python scripts/check_demo.py
```

Перший тест використовує окрему тимчасову папку та не витрачає ліміти ChatGPT. Публікація в демо — симуляція; повідомлення «Опубліковано» не означає надсилання в соцмережі. Деталі поточної реалізації: [IMPLEMENTATION.md](IMPLEMENTATION.md).
